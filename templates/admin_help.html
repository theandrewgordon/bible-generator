Admin Help & FAQs

Getting Started

Short answers for common tasks your team might do.

Themes

  • Switch theme: Go to Admin → Theme, select from the dropdown, click Save.
  • Preview: Click Preview to test without saving. Clear Preview to revert.
  • Live Preview: Use Start Live Preview to persist across navigation; Stop Live Preview to clear.
  • Create theme: Admin → Theme → “➕ New Theme”; pick colors, optional effects (snow, lights, leaves, etc.).
  • Clone theme: From a theme card, click Clone, adjust, Save.
  • Clone & activate: Use Clone, Save, then select in dropdown and Save.
  • Auto rules: Add multiple date/time/weekday rules under “Multiple Rules”. Higher priority wins if overlap.
  • Per-theme logo: On a theme card, upload a logo; it becomes active when that theme is selected.

Homepage Text & Banner

  • Announcement banner: Admin → Content. Toggle and set the banner text.
  • Homepage text: In the same place, edit title, subtitle, and call‑to‑action.

Collections & Packs

  • Create/edit: Admin → Collections. Add verses, mark public, order, and description.
  • Build download ZIP: Click “Rebuild ZIP”. Progress will update automatically.
  • Order: Use Save Order or arrows to reorder the grid.

Subscriptions

  • Plus page: /plus shows Family/Classroom buttons.
  • Promo codes: Enter codes directly on Stripe checkout. Ensure coupon/promotion exists in Stripe.
  • Billing portal: If subscribed, “🧾 Billing” appears in the navbar (for account management).

Troubleshooting

  • “No such price”: In env, set STRIPE_PRICE_* to a Price ID (price_…) or a Product ID (prod_…) with a default price.
  • Webhooks not updating Pro: Verify STRIPE_WEBHOOK_SECRET and events: checkout.session.completed, customer.subscription.deleted.
  • Thumbnails not loading: First load may generate them on demand; refresh if needed.
