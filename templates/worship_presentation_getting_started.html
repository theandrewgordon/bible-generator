Worship getting started

Import PowerPoint, PDF, and sermon notes

Keep the pastor’s slides in the service order and optionally turn the sermon notes into concise key-point suggestions that a person approves before projection.

Import a presentationAll worship help
The source design stays intactEach imported slide becomes a faithful static image. Faith Sparks does not rearrange its text or rebuild its layout. PowerPoint animations, transitions, and embedded videos are not included.

Open Import PowerPoint

On Plan Worship, open More → Import PowerPoint. Choose a .pptx or .pdf file up to 25 MB and 100 slides. If PowerPoint conversion is unavailable, export the deck as a PDF first.

Add the sermon notes if you have them

Paste an outline, manuscript, or speaking notes into Sermon notes. Speaker notes already stored inside a PPTX are included automatically.

Choose local or AI suggestions

Leave Use AI to suggest key points unchecked for private, local suggestions. Check it for AI-assisted suggestions; the pasted notes and PPTX speaker notes are sent to the configured AI provider and may create a small usage charge.

Import and review

Choose Import and review. Conversion can take a minute. On the review page, rename the presentation, drag slides into order, and uncheck any slide that should stay in the library without being projected.

Approve only the key points you want

Suggestions never appear on screen automatically. Edit their wording and check only the ones to project, then place them before or after the imported deck. Choose Look for key points again after changing the notes.

Save and place it in the service

Choose Save presentation. Back on Plan Worship, add it to This service, drag it to the correct spot, and use Review slides before going live.

If the layout looks wrong

Open the original deck, export it as PDF, and import the PDF. This usually gives the most faithful result when a PowerPoint uses unusual fonts or effects.

If no good key points appear

Add clearer notes with complete thoughts, Scripture references, and main ideas, then analyze again. Always compare every suggestion with the pastor’s intended meaning.
