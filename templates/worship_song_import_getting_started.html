Before you copy lyrics Use material your church is licensed or otherwise permitted to copy, store, and display. Faith Sparks helps organize the text; it does not provide lyric, chord-chart, or performance rights.

Open a reliable song page

Find the song on a source such as Worship Together, The Worship Initiative, the publisher’s website, or another source your church is permitted to use.

Pages that clearly label Verse, Chorus, Bridge, Tag, and repeats usually produce the best arrangement.

Copy the whole visible page

Click anywhere on the song page, select everything, and copy it. Including the page heading and song details helps Faith Sparks detect the title, artist, original key, and section order.

Windows / Chromebook: Ctrl + Athen Ctrl + CMac: ⌘ + Athen ⌘ + C

Open “New song or slide”

In Faith Sparks, open Worship, choose New song or slide, and scroll to Import with AI. Keep the Paste page tab selected.

Paste the page

Click the Paste lyrics or whole page field and paste what you copied.

Windows / Chromebook: Ctrl + VMac: ⌘ + V

You can usually leave the optional title, artist, version, and key fields blank. Fill one in only when you want to override what the importer detects.

Confirm permission and import

Check the permission confirmation, then choose Import Song. Faith Sparks removes common page navigation and footer text, finds the song details, separates the sections, and builds the likely arrangement.

Review before saving

On the review page, check the detected title, artist, key, arrangement, every lyric section, and the slide-by-slide preview.

  • If everything is correct, choose Confirm and Save Song.
  • If anything looks wrong, cancel the import and try a cleaner or more clearly labelled source.
  • AI can make mistakes, so always compare the result with your authorized source before presenting it.

What Faith Sparks should detect

  • Song title and artist
  • Original key when the page includes it
  • Verses, choruses, bridges, tags, intros, and outros
  • The repeated section order
  • Readable lyric slide breaks

If the import is messy

  • Use the page’s Lyrics view instead of a chord-heavy view.
  • Try copying the whole page rather than only a few lines.
  • Prefer a source with visible section labels.
  • If link import is blocked, use Paste page.
  • Add a permitted second source for validation when available.
